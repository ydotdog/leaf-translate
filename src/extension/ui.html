Connect this device, then ChatGPT

Run install-macos.command from the download (install-dia-macos.command for Dia) once to install the local sign-in component. No API key required.

Requires Node.js 22+. See the README for Linux installation.

Translates as you read, including dynamic content. Changes apply the next time you start translation.

Translation sends page text to OpenAI. Passwords and input fields are skipped. New tabs are not translated automatically.

From sign-in to reading in three steps

  1. Install the local component, then sign in with ChatGPT above.
  2. Allow eligible ChatGPT plan usage on the official consent page, then choose an available model.
  3. Open a webpage and click Leaf Translate in the toolbar to start bilingual reading.
Long pages translate near the viewport. Links, lists and tables keep their structure. Pause or restore the original at any time. Browser internal pages, PDFs, text in images, iframes and shadow DOM are not supported.

Shortcut: Alt + Shift + T. Change it in your browser’s extension shortcut settings.
